# UGV01 Physical Validation Dataset

This folder packages the current August 29, 2026 UGV01 AprilTag-referenced
physical-validation exports into a cleaner public-dataset layout.

The preferred current exports are the corrected elevation-calibrated runs listed
below. They supersede the older planar-reference exports for current analysis.

Each run directory contains:

- `aligned_samples.csv`: combined ground-truth and telemetry-aligned export in an
  i2Nav-like tabular format
- `aligned_samples.npz`: the same aligned export in compressed NumPy form
- `preparation_summary.json`: machine-readable provenance and summary metrics
- `source_telemetry.csv`: matched telemetry CSV used for the alignment/fidelity run
- `README.md`: per-run export summary generated by the packaging script

## Important notes

- The corrected runs use the fixed-tag ordering `1=top-left`, `2=top-right`,
  `3=bottom-right`, `4=bottom-left`.
- The independent reference is AprilTag plus ChArUco video geometry with
  elevation correction, not GPS.
- GPS is not included in these public exports; `gps_available` is `0`
  throughout.
- Camera and telemetry synchronization are inherited from the motion-correlation
  alignment used in the fidelity analysis; there is no dedicated hardware sync
  pulse in these pilot runs.
- The run-1 export is best interpreted as asset-specific calibration evidence.
  The run-2 and run-3 corrected exports are the stronger current holdout
  references for reporting cross-run behavior.
